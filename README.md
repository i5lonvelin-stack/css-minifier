# Free CSS Minifier

A free online CSS minifier tool to compress and optimize CSS code instantly.

## Features

- 🚀 Instant CSS minification
- 📊 Compression statistics (shows file reduction %)
- 📋 Copy to clipboard with one click
- ⬇️ Download minified CSS
- 📁 File upload support (drag & drop)
- 🌓 Dark/Light mode
- ✅ No signup required
- 🔒 Privacy-first (no data stored)

## Usage

1. Visit https://freecssminifier.com
2. Paste your CSS code or upload a file
3. Click "Minify CSS"
4. Copy or download your optimized code
